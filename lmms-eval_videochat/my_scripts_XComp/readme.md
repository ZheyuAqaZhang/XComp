Usage:

`TASK={taskname} MAX_NUM_FRAMES={max_frames} EXTRA_PARAM_SELECT_AND_DROP={QC-Comp selected n frames} EXTRA_PARAM_DUPLICATE={majority vote times} bash my_scripts_XComp/run.sh >{logfile}`

Example scripts:

mlvu: `mlvu-todo.sh`

videomme: `videomme-todo.sh`


Example logs:

mlvu: `mlvu_256_from_1024_dp2.log`

videomme: `videomme_512_from_1024_dp2.log`
